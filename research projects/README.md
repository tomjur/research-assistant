# Research projects

This directory holds the **research protocol**, **skills**, **scripts**, and **templates**. **Task artifacts** (prompts, TODO, graphs, logs, worker output, `FINAL_RESPONSE.md`) live under **`outputs/`** at the repository root: `outputs/<your-project-name>/<task-tldr>/`. See [Filesystem structure](RESEARCH_PROTOCOL.md#filesystem-structure).

## Start here

Read **[../AGENTS.md](../AGENTS.md)** (repo index), then **[RESEARCH_PROTOCOL.md](RESEARCH_PROTOCOL.md)**. For a new line of work, create `outputs/<your-project-name>/<task-tldr>/`, copy scaffolding from **[templates/](templates/)** if helpful, and follow **isolation** (stay inside one `{research-project-x}` under `outputs/`): [Filesystem structure](RESEARCH_PROTOCOL.md#filesystem-structure).
