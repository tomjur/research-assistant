# Research projects

All **inputs and outputs** for the research automation protocol live under this directory.

## Start here

Read **[../AGENTS.md](../AGENTS.md)** (repo index), then **[RESEARCH_PROTOCOL.md](RESEARCH_PROTOCOL.md)**. For a new line of work, create `research projects/<your-project-name>/<task-tldr>/` and copy scaffolding from **[templates/](templates/)** if helpful. Directory layout and **isolation** (stay inside one `{research-project-x}`): [Filesystem structure](RESEARCH_PROTOCOL.md#filesystem-structure).
